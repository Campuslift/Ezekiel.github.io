# Photo slots

Drop real photos here using these exact file names (JPG, ideally 1600 px wide).
Any slot left empty automatically shows its illustration instead.

| File                   | Used on                          | Suggested shot                         |
| ---------------------- | -------------------------------- | -------------------------------------- |
| `hero-students.jpg`    | Home hero                        | Students laughing together outdoors    |
| `campus-students.jpg`  | Home, About, Safety              | Students leaving campus                |
| `carpool-friends.jpg`  | Home, Find a ride, Offer a ride  | Friends sharing a car                  |
| `waiting-roadside.jpg` | Home, About                      | Student waiting at a roadside or stop  |

Use photos you took, have permission to use, or that carry a free licence
(Unsplash, Pexels). Photos found on Pinterest or Google Images are usually
copyrighted, so check the source before publishing.
Photos are cropped to 16:10, so keep faces away from the edges.
